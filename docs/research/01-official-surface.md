# Официальная поверхность Дзена: API, правила авторинга, комментарии, условия

Дата исследования: 2026-11-09. Трек 1 из 5 (только первоисточники). Этот отчёт
описывает, что Дзен **документирует**; реальное поведение Студии и внутренние
эндпоинты — зона другого воркера.

## Как читать этот отчёт

- **Подтверждено** — прямо сказано на странице dzen.ru/yandex.ru, ссылка рядом
  (короткие метки вида `[h-article]` расшифрованы в разделе «Источники»).
- **Вывод** — моё умозаключение из подтверждённых фактов.
- **Неизвестно** — документация молчит или проверить не удалось.

Метод. Firecrawl отказал (`Anonymous keyless access is unavailable`), поэтому
страницы получены обычным HTTP-запросом без авторизации, с задержкой 1 с. Обойдено
дерево `dzen.ru/help/ru/` по внутренним ссылкам (см. раздел «Покрытие») и основные
документы `dzen.ru/legal/ru/`. Все утверждения «не документировано» означают:
нет совпадений при поиске по этому корпусу после нормализации неразрывных пробелов.
Это ограниченное утверждение: закрытая партнёрская документация и страницы, на
которые нет ссылок, в корпус не входят.

## Главное для решения

1. **Публичного API для публикации или управления статьями и комментариями Дзен не
   документирует.** Нет ни API-справки, ни SDK, ни OpenAPI, ни OAuth-скоупа, ни
   тарифов. Бесплатного first-party API как варианта по умолчанию не существует
   (насколько можно установить по открытым источникам).
2. **Официальных автоматизируемых входов два, оба только на запись и оба узкие:**
   RSS-лента своего сайта и Telegram-бот `zen_sync_bot`.
3. **RSS умеет создавать черновики** через `<category>native-draft</category>`, но
   только при привязанном сайте с подтверждённым доменом, 10 подписчиках и
   прошедшей проверку ленте. Лента должна лежать на публичном URL, а раздел сайта,
   созданный только для ленты и закрытый для посетителей, прямо не допускается.
4. Ни RSS, ни бот **не дают** чтения черновиков, удаления, работы с комментариями и
   статистики. Для этого документированного программного пути нет.
5. **Удалить и опубликовать заново — опасный паттерн:** такие материалы считаются
   дубликатами и показываются только подписчикам, а удаление необратимо.
6. **Условия не упоминают сторонние CLI и клиенты явно** ни как разрешённые, ни как
   запрещённые. Есть широкий запрет на «обход ограничений» (п. 6.3) и запрет
   полностью автоматически созданного контента в правилах о спаме — это прямо
   касается авторинга через ИИ-агента. Цитаты в разделе 4.

## 1. API, SDK, партнёрские программы, RSS

### 1.1. API

**Подтверждено**

- Сервис оперирует ООО «ВК», документ в редакции от 21.10.2026 [l-terms]. Поэтому
  искать developer-портал стоит и у VK, и у Яндекса.
- Дзен предлагает автоматическую передачу материалов через RSS-ленту и
  Telegram-бот [h-mgmt]. Других программных каналов публикации в справке для авторов
  не описано.
- В разделе справки нет страниц об API: `dzen.ru/help/ru/api.html`,
  `/help/ru/api/index.html`, `/help/ru/developers/index.html` отвечают 404.
- Официальная партнёрская программа есть, но она про новости, а не про API.
  [Партнёрская программа Новостей][h-news-partners] описывает возможности «ИИ-Студию,
  адаптации текста, кросспостинг в MAX»; партнёром по соглашению может быть только
  учредитель СМИ [l-media]. Передача данных идёт через RSS-файлы (п. 3.1) [l-media].
- В Оферте монетизации встречается термин «программный интерфейс», но по определению
  это кабинет партнёра: «Интерфейс — программный интерфейс, предназначенный для
  удаленного взаимодействия Сторон в рамках Договора, который содержит информацию о
  Партнёре, перечень Контента, информацию касательно размера вознаграждения Партнёра,
  иную информацию, доступный Партнёру после авторизации с использованием Логина и
  пароля Партнёра на сайте Заказчика» [l-offer]. Это не описание developer API.

**Проверенные адреса (наблюдение, 2026-11-09)**

| Адрес | Результат |
| --- | --- |
| `https://dzen.ru/api/` | `{"error":1, "errtext":"Unknown api request"}` |
| `dzen.ru/developers`, `/dev`, `/api`, `/swagger`, `/openapi.json` | редирект на SSO Яндекса (так ведут себя и произвольные пути, поэтому ни о чём не говорит) |
| `dzen.ru/help/ru/api.html` и варианты | 404 |
| `dzen.ru/about/api` | 404 |
| `api.dzen.ru`, `developers.dzen.ru`, `publishers.dzen.ru` | имя не резолвится с этой машины |
| `yandex.ru/dev/zen/`, `yandex.ru/dev/dzen/`, `yandex.com/dev/zen/` | 404 |
| `yandex.ru/dev/` и `yandex.ru/dev/id/doc/ru/` | 200, упоминаний Дзена в HTML нет |

**Вывод.** С высокой уверенностью: открытого first-party API для статей и
комментариев нет. Косвенно это подтверждают сторонние лиды (ниже), но вес имеет именно
отсутствие в справке, условиях и на developer-порталах.

**Неизвестно**

- Существует ли закрытый API для крупных партнёров или по договору. В открытых
  документах следов нет; ответить могла бы только поддержка.
- Есть ли OAuth-скоуп Дзена у Яндекс ID или VK ID. Документация Яндекс ID описывает
  запрос прав из перечня, заданного при регистрации приложения [y-oauth], но перечня
  с Дзеном в открытых страницах не найдено. Авторизованный кабинет `oauth.yandex.ru`
  не проверялся по условиям задачи.
- Версии, лимиты, цены API: неприменимо, раз API не документирован.

### 1.2. RSS: состояние и возможности

**Подтверждено: RSS работает и продвигается.** Страницы актуальны на дату исследования
(в примерах встречаются даты 2025–2026 годов) [h-rss-modify] [h-export], раздел есть
на странице для медиа [a-media]. Цен за подключение ленты на изученных страницах нет.
Партнёрская программа Новостей описана как «возможность бесплатно увеличить посещаемость»
[h-news-partners]; про стоимость обычной ленты канала справка молчит.

Есть **две схемы** с разными правилами, и их важно не смешивать:

| | Лента канала (сайт автора) | Лента партнёра «Новости в Дзене» |
| --- | --- | --- |
| Справка | [h-rss-modify], [h-site] | [h-export] |
| Кто | любой канал с привязанным сайтом | партнёры сервиса Новости |
| Тип | `format-article`, `format-post`, автоконвертация | `<contentType>`: `news`, `news_only`, `blogs_only` |

**Требования для подключения ленты канала (подтверждено)**

- «нужно завести канал и набрать 10 подписчиков»; сайт соответствует требованиям;
  IDN-домены нельзя [h-site].
- Права на домен подтверждаются через HTML-файл или метатег в разделе «Свой сайт»
  [h-site]. Домен ленты должен совпадать с доменом сайта; один сайт можно привязать к
  нескольким каналам, у каждого своя лента [h-site].
- При первой разметке «лента должна содержать минимум 10 материалов. При этом на сайте
  должно быть размещено не менее 3 публикаций за последний месяц» [h-rss-modify].
- Лента проходит проверку. При технической ошибке повторить можно в любое время, при
  несоответствии контента — через 6 месяцев; Дзен может отклонить заявку без
  объяснения причин [h-site].
- Материалы сайта должны «находиться в свободном доступе». Пример нарушения: «Материал
  доступен только по прямой ссылке из Дзена, например, выложен в разделе, созданном
  для ленты RSS и закрытом для посетителей» [h-site-req].

**Что RSS умеет (подтверждено [h-rss-modify])**

| Возможность | Механизм |
| --- | --- |
| Создать **черновик** | `<category>native-draft</category>`: «материал сохранится на платформе в качестве черновика» |
| Опубликовать сразу | поведение по умолчанию, если способ не указан |
| Отложить публикацию | `pubDate`, минимум 1 час; для черновиков дата не действует |
| Выбрать формат | `format-article` / `format-post`, иначе автоконвертация по длине и картинкам |
| Обложка | `enclosure`, минимальная ширина 700 пикселей |
| Режим комментариев | `comment-all`, `comment-subscribers`, `comment-none` |
| Индексация | `index` / `noindex` |
| Обновить материал | тот же `guid`; «Ограничений на количество обновлений нет» |
| Объём | «не более 500 публикаций» за раз |

**Что ограничивает RSS (подтверждено)**

- Обновления работают «в течение 7 дней после первой загрузки» [h-rss-modify].
- «если вы внесёте изменение в публикацию вручную в Студии Дзена, то следующие
  изменения через RSS отображаться не будут» [h-rss-modify].
- Смена `guid` создаёт дубликат [h-export].
- Повторно добавлять материалы в ленту нельзя: материал «не считается актуальным, если
  когда-то уже был отправлен в Дзен через ленту RSS» [h-rss-modify].
- Технические пределы ленты новостной схемы: файл до 10 Мб, загрузка не дольше 10 с.
  Формулировка частоты дословно: «Робот скачивает файл от двух до пяти минут» [h-export].
- HTML только из перечня; «параметры, предназначенные для дополнительного оформления и
  сложной вёрстки, не обрабатываются» [h-rss-modify]. Яндекс Формы по RSS не
  переносятся [h-export].

**Вывод.** RSS годится как однонаправленный, официальный, «асинхронный» канал создания
черновиков, но не как API: синхронного ответа нет (идентификатор черновика и ошибки
разметки через ленту не возвращаются — в документации этого нет), контент сначала
появляется на публичном сайте, а требование о свободном доступе исключает приватную
«ленту-заглушку». Для сценария «написал Markdown — получил черновик» это рабочий, но
тяжёлый запасной путь.

**Неизвестно**

- Можно ли удалять материалы через RSS (удаление из ленты не описано).
- Как ведёт себя повторная отправка того же `guid` для `native-draft`, уже
  отредактированного в Студии, сверх общего правила о ручных правках.
- Точная периодичность опроса лент канала.

### 1.3. Telegram-бот и другие входы

**Подтверждено [h-telegram]**

- Бот «Синхробот Дзена» `zen_sync_bot` публикует посты из **публичного** телеграм-канала;
  один телеграм-канал на канал Дзена.
- Режимы: автоматически (по умолчанию) или вручную (пересылка поста боту, `/changemode`).
- Заголовок = первое предложение (до 140 символов), обложка = первая картинка,
  «Форматирование текста, применённое к посту в Телеграме, не будет перенесено».
- Текст, текст с картинками и текст с видео становятся статьёй; только картинка, только
  видео и опрос — постом; круглые видео, аудио, реклама с ERID и репосты не переносятся.
- Правки в автоматическом режиме подтягиваются, удаление поста в Телеграме статью в Дзене
  не удаляет. Создание черновиков ботом не описано.

Кросспостинг записей VK Видео Live тоже есть, но он только про стримы [h-mgmt].

**Вывод.** Telegram-бот не подходит для богато оформленных статей: форматирование теряется.

## 2. Правила авторинга

### 2.1. Типы публикаций

**Подтверждено.** В Студии четыре формата: Статьи, Посты, Видео, Ролики [h-studio].

| Формат | Лимиты |
| --- | --- |
| Статья | заголовок ≤ 140 символов, ссылки в заголовке запрещены; текст ≤ 100 000 символов с пробелами; вложений (картинки, видео, эмбеды) ≤ 100 [h-article] |
| Пост | ≤ 4 096 знаков с пробелами; ≤ 10 картинок, каждая ≤ 30 Мбайт; поддерживаются кириллица, латиница, эмодзи и встроенные ссылки [h-post] |
| Опрос в посте | 2–5 вариантов; заголовок ≤ 150, ответ ≤ 100 символов; нельзя вместе с картинкой или видео; после публикации не редактируется; создание только на десктопе [h-post] |
| Видео | от 5 секунд до 8 часов; до 70 Гбайт и 480 минут; теги ≤ 5 [h-video] |
| Ролики | отдельный короткий вертикальный формат [h-video] |

### 2.2. Блоки и форматирование статьи

**Подтверждено [h-article]**

| Элемент | Что документировано |
| --- | --- |
| Подзаголовки | «второго уровня» и «третьего уровня»; из них строится оглавление |
| Цитата, маркированный и нумерованный список | есть |
| Жирный, курсив, зачёркнутый, гиперссылка | есть |
| Картинка или GIF | загрузка файла или ссылка; ширина от 300 пикселей; до 30 Мб; подпись до 2 000 символов |
| Галерея | до 30 картинок |
| Видео | ссылка на Дзен или YouTube превращается в виджет; VK Видео через код вставки |
| Яндекс Формы | виджет на компьютере, в приложении ссылка |
| Упоминание канала | `@` и название канала [h-mobile-article] |

**HTML, разрешённый в RSS (подтверждено [h-rss-modify] [h-export])**: `p`, `a`, `b`, `i`,
`u`, `s`, `h1`–`h4` (`h1`,`h2` — первый уровень, `h3`,`h4` — второй), `blockquote`, `ul`/`ol`
с `li` (внутри `li` другое форматирование не поддерживается), якоря через `id` у заголовков,
`figure`/`img`/`figcaption`, `video` + `source` (MP4), `iframe`-коды вставки. Ссылки на Видео
Дзена, VK Видео и YouTube становятся виджетами автоматически. В постах из RSS поддерживаются
только гиперссылки и списки.

**Не документировано:** Markdown, таблицы, блоки кода и подсветка. Совпадений по корпусу нет.

**Вывод для конвертера Markdown:** безопасная цель — два уровня заголовков, абзацы, b/i/s,
ссылки, цитаты, плоские списки, картинки с подписями. Подчёркивание есть только в RSS.
Таблицы, код и вложенные списки нужно заранее решить как fallback (например, картинка или
плоский текст), а поддержку в реальном редакторе проверить отдельно.

### 2.3. Изображения, обложка, описание

**Подтверждено**

- Форматы при RSS: JPEG, GIF, PNG; при неверном формате материал выйдет без картинки
  [h-rss-modify]. Для обычной загрузки в редактор список форматов не указан [h-article].
- Обложку нужно выбрать, иначе «вместо неё в ленте отобразится серый квадрат»; по умолчанию
  берётся первое изображение статьи [h-card].
- Описание карточки «генерируется автоматически на основе первых предложений из публикации.
  Вы не можете его отредактировать» [h-card]; в карточке до 1 000 символов текста [h-card].
- Рекомендованная длина заголовка 15–25 символов; запрещены кликбейт, ссылки, омоглифы,
  «программный код», большое количество заглавных букв и знаков препинания [h-card].

### 2.4. Теги и темы

**Подтверждено.** Теги документированы только для видео (не более 5) [h-video]. Для статей
есть **подборки**: до 1 000 публикаций, название ≤ 80, описание ≤ 300 символов, обложка ≤
10 Мб, число подборок не ограничено [h-collections]. Новостной RSS принимает
`<category>` с рубрикой сайта и `theme_tags` [h-export].

**Неизвестно.** Есть ли у статей темы, задаваемые автором; страница статьи таких полей не
описывает [h-article].

### 2.5. Настройки публикации и статусы

**Подтверждено [h-article]**

- Перед публикацией: заголовок, обложка, отложенная дата, кто может читать (уровни Премиум;
  «Из коллекции автора» за 1 Стеллу; открытая статья), кто может комментировать, отметка
  «Партнёрский материал».
- Статусы: Черновик, Ожидает публикации, Опубликовано, В обработке, Есть неопубликованные
  правки, Заблокировано.
- После «Опубликовать» материал проверяется «от нескольких минут до нескольких часов».
- Закрепить можно до 3 материалов.

### 2.6. Отложенная публикация

**Подтверждено [h-delayed]**: для постов, статей, роликов и видео; минимум час, максимум 365
дней (ролики в iOS — минимум 3 часа); по местному времени автора; дата меняется через
редактирование; при удалении до даты материал не выходит.

### 2.7. Черновики

**Подтверждено**

- Вкладка «Черновики» в разделе «Публикации»; доступ к черновикам входит в совместный
  доступ [h-studio] [h-access].
- В мобильной Студии черновики и правки «сохраняются на сервере Дзена и доступны с любых
  устройств»; при плохой связи автосохранение может не сработать [h-mobile-article].

**Неизвестно.** Срок хранения и лимит количества черновиков не указаны.

### 2.8. Редактирование, удаление, скрытие

**Подтверждено [h-article]**

- Опубликованную статью можно редактировать; это «не повлияет на «возраст» статьи, её
  отображение в ленте рекомендаций и уже набранную статистику». На время редактирования
  статья не показывается в ленте, но доступна по прямой ссылке. Правки можно отменить кнопкой
  «Удалить правки». Лента обновляется «через несколько минут».
- Удаление доступно из вкладок Опубликованные, Ожидают публикации, Черновики.
  «Удалённую статью нельзя восстановить».
- Дубликатами считаются материалы, «удалённые из Дзена и опубликованные заново», а также
  «повторно опубликованные на одном канале»; они показываются только подписчикам [h-copypaste].
  Публикация на нескольких своих каналах считается заимствованием [h-copypaste].

**Не документировано:** снятие с публикации, скрытие, возврат в черновик. Документирован
только полный цикл «редактировать» и «удалить».

### 2.9. Модерация и санкции

Термина «страйк» в справке нет; есть раздел «Предупреждения» в профиле Студии [h-studio].

**Подтверждено**

- Три модели показа: рекомендуется в ленте; только подписчикам; блокировка [h-models].
- Одна нарушающая публикация видна только подписчикам; несколько или серьёзные нарушения —
  все публикации только подписчикам; при многократных или грубых нарушениях публикации
  перестают показываться всем; доход перестаёт начисляться [h-pessimization].
- Перепроверка публикации: только один раз, «до 15 публикаций в сутки», кнопка активна
  неделю, занимает около двух часов; недоступна для авторских прав, дублей, ссылочного спама
  и блокировок РКН [h-recheck].
- Проверка канала: «не более трёх в год», для каналов с заимствованным контентом — одна
  [h-pessimization]. Перед ней нужны 5 активных материалов (кликбейт), 5 новых (прочие
  нарушения) или 10 новых (заимствование); проверка автоматизирована [h-restrictions].
- Искусственное завышение показателей: «Каналы с подобным нарушением будут заблокированы»
  [h-rules].
- Условия: Компания может заблокировать учётную запись «в случае неоднократного нарушения
  Условий» (п. 4.7) [l-terms].

## 3. Комментарии

**Подтверждено** ([h-comments], [h-comments-user], [h-comments-req])

- Комментировать и ставить реакции могут только авторизованные пользователи.
- Настройка **на публикацию**: Все, Подписчики, Никто. Настройки на уровне канала не описано.
  При закрытии старые комментарии «будут скрыты, а не удалены» и вернутся при включении.
- Лимиты: 2 500 знаков с пробелами; «не поддерживают вставку кликабельных ссылок и
  форматирование текста»; редактирование в течение часа; картинки JPG/PNG до 20 Мб только
  с Дзен Про или у премиум-подписчиков под премиум-публикациями.
- Частота: «Количество комментариев не ограничено. При большом количестве попыток написать
  комментарий за короткое время может появиться капча» [h-comments-user].
- Комментарии автора подписаны названием канала; комментировать под своим именем можно
  только с другого аккаунта.

Действия автора:

| Действие | Детали |
| --- | --- |
| Просмотр | Студия → Комментарии; фильтры: все или неотвеченные, все пользователи или подписчики |
| Ответ | ответ в ветке, сортировка внутри ветки хронологическая |
| Оценка | реакция с уведомлением автору комментария |
| Закрепление | только комментарий первого уровня |
| Удаление | по одному; отмена «Восстановить» до обновления страницы |
| Блокировка | только на своём канале, только по одному; можно удалить все комментарии пользователя без возможности восстановления; раздел «Чёрный список» в настройках |
| Жалоба | анонимная, на комментарий или пользователя |
| Скрытие отдельного комментария автором | **не документировано**. После жалобы комментарий «будет автоматически скрыт от вас»; при жалобах других пользователей «может быть скрыт ото всех» |

«Автор канала имеет право удалять любые комментарии под своей публикацией и заблокировать
комментатора без объяснения причин» [h-comments-user]. Удаление комментариев доступно ролям
Владелец, Администратор, Редактирование [h-access].

Спамом в комментариях считается, в частности, «многократное повторение одного и того же
комментария без смысловой нагрузки» [h-comments-req].

## 4. Частота публикаций, антиспам, автоматизация

### 4.1. Лимиты частоты

**Подтверждено.** Общего лимита числа публикаций в день в справке и условиях не найдено.
Численные ограничения, которые есть: 500 публикаций за раз в RSS [h-rss-modify], 15 перепроверок
в сутки [h-recheck], капча при частых комментариях [h-comments-user], минимум час для отложенной
публикации [h-delayed].

**Неизвестно.** Есть ли негласные лимиты. Документация об этом молчит.

### 4.2. Спам и автоматически созданный контент

Дословно, [h-spam]:

> В Дзене запрещён контент, который полностью или почти полностью создан автоматически, без участия автора. Как правило, он не несёт смысловой нагрузки для аудитории. К нему относятся:
> - автоматические переводы с других языков без редактуры;
> - автоматически сгенерированные тексты;
> - автоматически сгенерированная озвучка видео и звуковые дорожки;

Контентный спам — материалы, которые «оставляют впечатление публикаций, созданных по шаблону» и
содержат «сюжетные конструкции, повторяющиеся от одного материала к другому». Такие публикации
показываются только подписчикам; «Каналы и сайты с большим количеством спама
недоступны на платформе» [h-spam].

Понятие «с участием автора» в справке не определено; порога и метода обнаружения нет. Отдельного
правила про ИИ-ассистентов как инструмент автора в справке не найдено: ИИ в корпусе упоминается как
собственные инструменты Дзена (ИИ-Студия для партнёров [h-ai-studio], ассистент Глиф [h-pro]).

## 5. Модель аккаунта и каналов

**Подтверждено**

- Вход через VK ID или Яндекс ID; войти можно только тем способом, что использован при
  регистрации [h-registration].
- «К каждому аккаунту VK ID или Яндекс ID может быть привязан один канал в Дзене» [h-mgmt].
- Несколько каналов из одной Студии — через совместный доступ со своего другого аккаунта;
  переключение выпадающим списком [h-access]. Получатель доступа должен иметь свой канал, а
  почта должна совпадать с указанной в его Контактах [h-access].
- Администраторы управляют каналом только через веб-браузер [h-access].
- Удаление канала стирает публикации и комментарии [h-mgmt]. Перед первой публикацией может
  потребоваться подтверждение контактных данных [h-mgmt].
- Обязательная авторизация по телефону и запрос документов возможны по решению Компании
  (пп. 4.3.1, 4.3.2, 4.4.2) [l-terms].

Матрица ролей [h-access]:

| Право | Владелец | Администратор | Редактирование | Просмотр |
| --- | --- | --- | --- | --- |
| Управление заработком | да | нет | нет | нет |
| Назначение администраторов | да | нет | нет | нет |
| Удаление комментариев | да | да | да | нет |
| Делегирование доступа | да | да | нет | нет |
| Добавление, редактирование, удаление публикаций | да | да | да | нет |
| Настройка канала | да | да | да | нет |
| Создание подборок | да | да | да | нет |
| Просмотр статистики | да | да | да | да |
| Просмотр баланса | да | да | да | да |
| Продвижение | да | да | да | нет |

Значения восстановлены по значкам-галочкам в HTML-таблице страницы. Доступ выдаётся на весь канал, а не на отдельные публикации
[h-access]. Сервисных аккаунтов и токенов доступа в справке нет.

**Вывод.** Роль «Редактирование» — документированный способ дать инструменту отдельный аккаунт с
правом создавать и удалять публикации и комментарии, но без доступа к деньгам и назначению
администраторов. Этому аккаунту нужен свой канал [h-access].

## 6. Статистика

**Подтверждено** ([h-stats], [h-stats-ext], [h-stats-realtime], [h-stats-sub], [h-stats-aud],
[h-stats-rss], [h-studio])

- Разделы: Подписчики, Публикации, Почасовая статистика (48 часов, топ 20), Доход, Аудитория.
- По статьям: показы, дочитывания, процент чтения (карта дочитываний при более чем 100
  дочитываниях), CTR в ленте, подписки, комментарии, лайки, «Поделиться», время просмотра.
- По постам: показы, просмотры, комментарии, VTR, лайки, «Поделиться», время просмотра.
- Разбивка по платформам: Дзен, ОК, Mail.ru; фильтр «Только подписчики»; отчёт по дате
  события или по дате публикации; детализация по дням, неделям, месяцам.
- Аудитория: подписчики и вся аудитория, источники, время, пол и возраст, устройства, ОС.
- Выгрузка XLSX через кнопку «Отчёт»; для RSS-раздела до 15 000 публикаций. Счётчик Метрики
  и других сервисов подключается (один счётчик от каждого сервиса) [h-mgmt].
- Точность: данные за последние 24 часа могут меняться из-за антифрода; время просмотра с
  задержкой 2 дня; комментарии и лайки в таблицах считаются с учётом удалённых и снятых; отметки
  «Не нравится» не учитываются.

**Неизвестно.** Программный доступ к статистике не документирован.
